# Автоматическая жанровая анимация музыки — спецификация

## Цель

Добавить в Cyclop режим «Автоматически по жанру». Когда Яндекс Музыка публикует
системный Now Playing-трек, Cyclop определяет жанр произведения через публичный
каталог Яндекс Музыки и выбирает подходящую анимацию в компактном острове.
Ручные анимации остаются доступными и не меняют своё поведение.

## Границы

- Поддерживается только источник с отображаемым именем `Yandex Music` или
  `Яндекс Музыка`.
- Используются уже получаемые из системного Now Playing название, исполнитель
  и альбом. Cyclop не читает интерфейс приложения, не использует Universal
  Access, закрытые API, cookies, пароль, OAuth-токен или данные аккаунта.
- В публичный каталог уходит только запрос поиска текущего трека. Запрос не
  выполняется для Apple Music, Spotify, браузеров или любого неизвестного
  источника.
- Сетевой результат не является необходимым для интерфейса: остров никогда не
  ждёт ответ и при любой неопределённости использует «Универсальный» стиль.
- Первая версия не сохраняет историю прослушивания на диск. Кэш существует
  только в памяти процесса Cyclop и очищается при выходе из приложения.

## Текущий контекст

`MediaController` уже публикует `MediaState` с `Track` (`title`, `artist`,
`album`, `key`) и `sourceName`. `MediaActivitySource` адаптирует эти данные в
`MediaActivityPayload`, а `CompactActivityView` передаёт выбранный режим
`MediaEqualizerView` напрямую из `ActivitySettings`.

Эта спецификация не меняет транспорт воспроизведения, MediaRemote helper,
обложку, команды плеера или контракт `MediaActivitySource`. Новый сервис
работает рядом с существующим потоком и поставляет только вычисленный стиль
анимации и его человекочитаемое описание.

Документация activity center запрещает provider-specific scraping, Universal
Access и закрытые интеграции. Данное решение этим правилам соответствует:
источником остаётся системный Now Playing, а внешний каталог используется как
read-only lookup без аутентификации. После реализации документация и ручная
матрица должны быть дополнены этой возможностью.

## Модель настройки и стиля

Настройка и фактическая анимация разделяются.

- `MediaAnimationMode` — пользовательский выбор: `off`, `automatic` и ручные
  стили.
- `MediaAnimationStyle` — конкретный стиль, который рисует
  `MediaEqualizerView`. В нём нет `automatic`; resolver всегда превращает его
  в конкретный стиль.
- Сохранённые значения `static`, `slow`, `fluid`, `rock` и `rockHits`
  продолжают мигрироваться так же, как в текущей версии. Неизвестное значение
  настройки безопасно становится `universal`.

При ручном режиме фактический стиль равен выбранному стилю. При `off` остров
не показывает эквалайзер. При `automatic` до завершения надёжного определения,
а также при ошибке, используется `universal`.

## Палитра и таблица жанров

В пользовательском интерфейсе все названия отображаются на русском. Палитра
состоит из 17 стилей; они имеют различающиеся форму, темп и акцент, а не только
разные множители скорости.

| Стиль | Начальные теги каталога | Характер |
| --- | --- | --- |
| Рок: Рифф | `rock`, `rusrock` | риффовый, уверенный рисунок |
| Рок: Стена | `hardrock`, `grunge` | плотный гитарный поток |
| Панк | `punk`, `hardcore` | короткие резкие импульсы |
| Металл | `metal`, `alternativemetal` | плотная быстрая стена |
| Альтернатива / инди | `alternative`, `indie` | неровная живая волна |
| Поп | `pop`, `ruspop` | ровные мелодичные подъёмы |
| Танцевальная | `dance`, `eurodance`, `hyperpopgenre` | пружинящий танцевальный ритм |
| Электроника | `electronics`, `experimental` | синтезаторные пульсации |
| Техно / house / trance | `techno`, `house`, `trance` | ровный четырёхдольный пульс |
| Breakbeat / DnB | `breakbeatgenre`, `drumandbass` | быстрый ломаный ритм |
| Рэп | `rap`, `rusrap` | низкие акцентные удары |
| Лоу-фай / ambient | `lofi`, `ambient`, `chill`, `relax` | медленное дыхание |

Таблица живёт в чистом типе без сетевого кода. Сравнение тегов
регистронезависимое. Один жанр всегда возвращает один стиль; неизвестные теги
никогда не угадываются.

## Определение жанра

`GenreAnimationResolver` наблюдает состояние музыки только когда настройка
равна `automatic`.

1. Проверяет точное имя источника: `Yandex Music` или `Яндекс Музыка`.
2. Проверяет непустые название и исполнитель. Альбом желателен, но не обязателен.
3. Строит ключ запроса из нормализованных названия, исполнителя и альбома.
4. Возвращает сохранённый в памяти результат, если этот ключ уже известен.
5. Иначе выполняет публичный read-only поиск трека в Яндекс Музыке.
6. Выбирает кандидат только по строгому счёту: точное название — 65 баллов,
   совпадение хотя бы одного исполнителя — 30, точный альбом — 10. Результат
   принимается при 95 и более баллах.
7. Берёт `genre` альбома совпавшего кандидата и применяет таблицу стилей.
8. Сохраняет положительный или отрицательный итог в memory cache и публикует
   разрешение для текущего ключа.

Жанры исполнителя не используются для выбора анимации: они могут описывать
всю карьеру и не конкретный релиз. Они допустимы только как диагностическая
информация в отладочном логе, но не сохраняются и не показываются пользователю.

Каждый асинхронный запрос имеет generation token. Смена трека, отключение
автоматического режима, смена источника или остановка композиции делают
предыдущий ответ устаревшим: он не имеет права изменить стиль нового трека.

## Сеть, ошибки и поток выполнения

Live-клиент каталога скрыт за протоколом, чтобы unit-тесты использовали fake и
не выходили в интернет. Он выполняет URLSession-запросы вне главного потока,
имеет ограниченный таймаут и не делает повторных попыток в первой версии.

- Таймаут, недоступность сети, некорректный JSON, пустой ответ и HTTP-ошибка
  равны отрицательному результату для текущего запуска.
- Ошибки не показываются пользователю и не прерывают проигрывание.
- В острове до и после неуспешного lookup остаётся универсальная анимация.
- Никакие сетевые ответы не логируются вместе с полными метаданными трека в
  release-сборке.

## UI

В Picker «Анимация музыки» появляются: «Выкл», «Автоматически по жанру»,
«Универсальный» и все ручные стили из таблицы. Существующие ручные варианты
«Рок: Рифф» и «Рок: Стена» сохраняются как самостоятельные стили; их
сохранённые значения и рисунки не меняются. Новые стили добавляются рядом с
ними.

Компактный остров сохраняет существующую композицию: название трека, бегущая
строка и эквалайзер. Жанр в нём не добавляется, чтобы не уменьшать место для
названия. В раскрытой вкладке «Музыка» появляется вторичный текст вида:
`Жанр: Breakbeat / DnB · анимация выбрана автоматически`.

Если жанр ещё определяется, жанр не отображается до ответа; стиль в острове
остаётся универсальным. При ручном стиле строка состояния жанра не показывается.

`Reduce Motion` и пауза должны сохранить текущую семантику: при паузе движение
эквалайзера останавливается, бегущая строка продолжает работу; при включённом
Reduce Motion эквалайзер не анимируется.

## Встраивание

`ActivityComposition` создаёт один resolver и передаёт его в UI-слой музыки.
Resolver зависит от `MediaController`, `ActivitySettings`, абстракции клиента
каталога и scheduler/clock только там, где это необходимо для отмены и тестов.
`MediaActivitySource` не получает сетевую ответственность и не меняет свои
snapshots.

`CompactActivityView` получает разрешённый `MediaAnimationStyle`, а не читает
настройку напрямую. Раскрытая `MediaPane` получает read-only presentation
resolver-а для вторичного текста жанра.

## Тестирование и приёмка

### Unit-тесты

- Миграция всех старых значений настройки и сохранение нового `automatic`.
- Русские подписи всех режимов настройки.
- Таблица тегов: каждый тег из спецификации, регистронезависимость и fallback
  в `universal`.
- Строгое сопоставление: 95/105-балльный кандидат принимается; совпадение
  только названия, иной исполнитель и иной альбом отвергаются.
- Resolver: разрешённый Yandex source, запрещённые Apple Music/Spotify/browser,
  memory cache, отрицательный cache, ошибка клиента, быстрые переключения и
  устаревший ответ.
- Политика равномерной анимации для каждого стиля: воспроизведение, пауза,
  `Reduce Motion` и `off`.
- UI presentation: автоматический статус и жанр появляются только в
  раскрытой музыкальной вкладке.

### Ручная приёмка

Дополнить `docs/testing/activity-media-manual-matrix.md` колонкой проверки
автоматической анимации для нативной Яндекс Музыки: треки разных жанров,
быстрое переключение, отключённая сеть, неизвестный тег и восстановление
воспроизведения после паузы. Для Apple Music, Spotify и браузеров убедиться,
что их метаданные не вызывают сетевой lookup и сохраняют ручной/универсальный
режим.

## Критерии готовности

- В автоматическом режиме совпавший трек Яндекс Музыки меняет стиль не позже
  завершения lookup и без блокировки острова.
- Несовпавший или недоступный трек всегда остаётся универсальным.
- Имена и метаданные треков других провайдеров не отправляются в каталог.
- Все существующие тесты Cyclop и новые unit-тесты проходят.
- Ручная матрица фиксирует фактический результат на целевой macOS.
