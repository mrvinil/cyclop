# Укрепление надёжности и безопасности загрузок — дизайн

## Цель

Устранить подтверждённые риски в собственном загрузчике Cyclop и телесуфлёре, не меняя CI и не расширяя пользовательский функционал.

## Границы

В работу входят только четыре изменения:

1. Cyclop помечает создаваемые файлы системным карантином macOS.
2. Восстановление незавершённой финализации загрузки не может записать файл вне выбранной пользователем папки загрузок.
3. Текст телесуфлёра немедленно сохраняется при остановке приложения.
4. Запущенный телесуфлёр прекращает прокрутку и закрывает панель по Escape или по клику вне панели.

GitHub Actions, новые разрешения macOS, новая история загрузок и изменение формата хранилищ не входят в работу.

## Архитектура

### Карантин файлов

`Scripts/bundle.sh` добавляет `LSFileQuarantineEnabled=true` в создаваемый `Info.plist`. Это использует системный механизм Launch Services: файлы, которые создаёт Cyclop, получают метку происхождения и при открытии проходят стандартную проверку macOS. Дополнительного разрешения или ручного вызова `xattr` не требуется.

### Безопасное восстановление загрузок

`DownloadManager` уже является владельцем настроек и знает выбранную папку загрузок. Поэтому он проверяет путь из журнала непосредственно перед перемещением или открытием восстановленного файла. Допустим только путь внутри текущей папки загрузок после стандартизации и разрешения символьных ссылок. Журнал с другим путём считается некорректным: staged-файл не перемещается, менеджер показывает существующую ошибку восстановления и не создаёт каталог по пути из журнала.

Базовая структурная проверка `DownloadFinalizationStore` сохраняется: она отвечает за корректность JSON, UUID и тип URL; бизнес-правило о пользовательской папке остаётся в `DownloadManager`.

### Жизненный цикл телесуфлёра

`NotchViewModel.stop()` вызывает `teleprompter.flush()` рядом с уже существующим `notes.flush()`. При выходе отменённая дебаунс-запись заменяется синхронным сохранением текста.

`NotchPanel` получает точку обратного вызова для Escape. `NotchController` передаёт её в модель: если телесуфлёр удерживает панель открытой, он приостанавливается и панель закрывается. Для клика вне панели `PointerWatcher` не должен игнорировать уход указателя, когда телесуфлёр запущен: он выполняет ту же явную остановку и закрытие, после чего не перехватывает сам клик.

## Ошибки и безопасная деградация

- Некорректный журнал не создаёт каталог и не перемещает staged-файл в произвольное место.
- Существующее сообщение о недоступности восстановления сохраняется; пользователь не получает ложного статуса «загрузка завершена».
- Escape вне режима телесуфлёра сохраняет текущую обработку клавиатуры и не меняет другие вкладки.
- Клик вне панели по-прежнему должен достаться приложению под панелью.

## Проверка

Тесты должны покрывать:

1. Неподходящий путь журнала не приводит к перемещению staged-файла и не создаёт внешний каталог.
2. Допустимый путь в выбранной папке продолжает финализироваться.
3. Остановка `NotchViewModel` вызывает сброс отложенной записи телесуфлёра.
4. Escape и уход указателя при запущенном телесуфлёре останавливают его и закрывают панель, без изменения поведения остальных вкладок.
5. Сборочный скрипт кладёт ключ карантина в `Info.plist`; это проверяется существующим bundle-smoke-тестом или отдельной проверкой plist.

## Ограничения

- macOS 15.0+.
- Интерфейс и сообщения для пользователей остаются на русском.
- Не добавлять зависимости и разрешения macOS.
- Не менять CI в этой задаче.
